# 苹果 · 双侧光照

直接用现代浏览器打开 `dist/index.html`。HTML 内嵌原有苹果 GLB 模型和 Three.js，无需联网或后端服务。

- 拖动旋转，滚轮缩放；触屏支持单指旋转和双指缩放。
- 左右滑块分别调节左上方暖光和右上方冷光。
- 两盏聚光灯都参与实时照明和阴影计算，柔和的锥形透明光束用于表现空中散射效果。
- 点击“自动旋转”开始或暂停环绕查看，“重置视角”回到初始位置。
- 聚焦三维画面后，也可使用方向键旋转、加减键缩放。

需要支持 WebGL 2 的浏览器及可用的图形加速。网页是静态文件，内部的三维画面由浏览器实时渲染。

## 修改与打包

`src/main.js` 控制三维场景，`src/page.html` 控制页面布局。运行 `npm run build` 会重新生成 `dist/index.html`，并读取上一级目录中的 `first_apple/apple.glb`。
